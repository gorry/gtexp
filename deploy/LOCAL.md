# 自分のパソコンで使う（Windows・Mac）

サーバーを用意せずに、自分のパソコンの中だけで gtexp を動かす方法です。パソコンで gtexp を起動し、同じパソコンのブラウザーで開いて使います。
取り込んだデータは、パソコンの gtexp のフォルダーの中に保存されます。

サーバーに設置して、スマホなどほかの端末からも使う方法は [README.md](README.md) を参照してください。

## できること・できないこと

- タイムラインの取り込み・閲覧・集計・エクスポートなど、画面の機能はサーバーに置いたときと同じように使えます
- Chrome・Edge では、PWA としてインストールして、アプリのように開けます
- 使えるのは、gtexp を起動しているパソコンからだけです。スマホやほかのパソコンからはつながりません（スマホの「共有」から直接取り込むこともできません。エクスポートしたファイルをパソコンに移して取り込みます）
- 地図を表示するには、Google Maps の API キーが必要です（「6」を参照）。なくても、地図以外の機能は使えます
- 住所のデータ（位置参照情報）と、OpenStreetMap の施設名・住所は任意です。入れなくても動きます

## 1. Node.js を入れる

[Node.js](https://nodejs.org/) の LTS 版（22.13 以上）を入れます。

- Windows・Mac：サイトからインストーラーをダウンロードして実行します
- Mac で Homebrew を使っている場合：`brew install node` でも入れられます

入ったかどうかは、ターミナル（Windows は「PowerShell」または「ターミナル」、Mac は「ターミナル」）で次のように確認できます。

```sh
node --version     # v22.13.0 以上（v24 など）が表示されれば OK
```

## 2. gtexp を取得する

次のどちらかで取得します。

- Git を使う場合：

  ```sh
  git clone https://github.com/gorry/gtexp.git
  cd gtexp
  ```

- Git を使わない場合：GitHub の [gorry/gtexp](https://github.com/gorry/gtexp) で「Code」→「Download ZIP」を選び、ダウンロードした zip を展開します（`gtexp-main` というフォルダーができます）。ターミナルでそのフォルダーに移動します
  - この方法の場合、「このアプリについて」画面のビルドの欄は「不明」と表示されます（動作には影響しません）

以降のコマンドは、すべてこのフォルダーの中で実行します。

## 3. ビルドする

```sh
npm ci
npm run build
```

`npm ci` は、ビルドに使う部品をダウンロードします（初回は少し時間がかかります）。

## 4. ユーザーを作る

```sh
node dist/server.mjs user-add alice
```

`alice` の部分は好きなユーザー名にします（英小文字・数字・`_`・`-` で 32 文字まで）。パスワードを 2 回聞かれるので、入力します。

## 5. 起動して開く

```sh
node dist/server.mjs serve
```

起動したら、ブラウザーで http://localhost:8787/ を開き、「4」のユーザー名とパスワードでログインします。

- 使っている間は、ターミナルの画面を閉じないでください。止めるときは、ターミナルで `Ctrl` + `C` を押します
- 次に使うときも、ターミナルでこのフォルダーに移動して `node dist/server.mjs serve` を実行します
- PWA としてインストールするには、Chrome・Edge のアドレスバーの右にあるインストールのボタンを押します（インストールしたアプリも、gtexp を起動しているときだけ使えます）

## 6. 地図を表示する（任意）

1. [README.md](README.md) の「6. Google Maps の API キーを作る」に従って、API キーを作ります。キーの制限の「ウェブサイト」には `http://localhost:8787/*` を追加します
2. 設定ファイルを作ります

   ```sh
   # Windows（PowerShell）
   Copy-Item deploy/gtexp.config.example.json gtexp.config.json
   # Mac
   cp deploy/gtexp.config.example.json gtexp.config.json
   ```

3. `gtexp.config.json` をメモ帳やテキストエディターで開き、`mapsApiKey` の値（`（Maps JavaScript API のキー）` の部分）を作ったキーに書き換えて保存します
4. gtexp を止めて（`Ctrl` + `C`）、もう一度 `node dist/server.mjs serve` で起動します

設定ファイルがなくても、既定の設定（`http://localhost:8787/`、データは `data` フォルダー）で動きます。設定ファイルを作るのは、地図を表示するときや、ポート番号などを変えるときだけです。

## 7. データを取り込む

1. Android 端末で「設定」→「位置情報」→「位置情報サービス」→「タイムライン」→「タイムライン データをエクスポート」でファイルを保存します
2. そのファイルをパソコンに移します（Google ドライブ、USB ケーブル、メールなど）
3. gtexp の「データの取り込み」画面の「ファイルを選択」で取り込みます。まだデータがないときは、ログインするとこの画面が開きます（あとからは、右上の「≡」→ユーザー名→「データの取り込みを開く」で開きます）

Google Takeout・Foursquare Swarm のエクスポートも、同じ画面から取り込めます。

## 8. 更新する

gtexp を止めてから、次のようにします。

- Git で取得した場合：

  ```sh
  git pull
  npm ci
  npm run build
  ```

- ZIP で取得した場合：新しい ZIP をダウンロードして展開し、古いフォルダーから `data` フォルダーと `gtexp.config.json`（作った場合）を新しいフォルダーへコピーしてから、新しいフォルダーで `npm ci` と `npm run build` を実行します

そのあと、`node dist/server.mjs serve` で起動します。

## 9. データの場所とバックアップ

取り込んだデータ・ユーザー・ログインの鍵は、すべて gtexp のフォルダーの中の `data` フォルダーにあります。

- バックアップは、gtexp を止めてから `data` フォルダーごとコピーします
- `data` フォルダーの中の `session.key` は、ログインの状態と 2 段階認証の鍵を守るためのものです。なくすと、ログインし直しが必要になり、2 段階認証も読めなくなります（`node dist/server.mjs user-mfa-reset <名前>` で外して、設定し直してください）
- ほかに、名前・メモ・タグとブックマークは、「データの取り込み」画面からエクスポート（JSON）しておくこともできます

## 10. 設置の確認（任意）

```sh
node dist/server.mjs check
```

設置の状態を確認できます。自分のパソコンで使う場合は、次の「注意」「情報」は無視してかまいません。

- 設定ファイルがない（設定ファイルを作っていない場合）
- `mapsApiKey` が設定されていない（地図を使わない場合）
- ログのフォルダーがまだない
- サービスの定義が入っていない
- サーバーが動いていない（gtexp を起動していないときに実行した場合）
- cron に fetch-osm の行がない

## 11. 住所・施設名のデータ（任意）

サーバーと同じ手順で入れられます。[README.md](README.md) の「9. 住所のデータを入れる」「10. OpenStreetMap の施設名と住所」を参照してください。

- OpenStreetMap の住所を毎時少しずつ取得する定期実行（cron）は、自分のパソコンでは設定しなくてかまいません。住所が取得されないだけで、ほかの機能は使えます
- `deploy/` の中のシェルスクリプト（`.sh`）は、Windows ではそのままでは動きません。施設データを作る `make-osm-poi.sh` を使う場合は、Mac や Linux、または Windows の WSL で実行してください

## うまく動かないとき

- `EADDRINUSE: address already in use` と出て起動しない：ほかのアプリがポート 8787 を使っています。設定ファイルに `"port": 8788` のように別の番号を書き、`http://localhost:8788/` で開きます（地図の API キーの制限にも、その番号の URL を追加します）
- `node:sqlite` などのエラーで起動しない：Node.js が古い可能性があります。`node --version` で 22.13 以上か確認してください
