## GUI メッセージ・文言の精査と改善指針の策定（`memo/doc/gui-format-problem.md`）
- ユーザーの指示：画面（GUI）に表示されるメッセージや文言のうち、開発側の事情（内部閾値やファイル保持挙動など）がそのまま露出しているものや、AI から開発者への実装報告調になっているもの、標準的な UI 用語を過度に口語・大和言葉へ言い換えて不自然になっているものを洗い出し、開発者と当該 AI が参照する指針文書として `memo/doc/gui-format-problem.md` にまとめる
- 分析した主な課題
  1. 内部アルゴリズム・距離閾値（`2m 以内`、`30m 以内`、`150m 以内`、`15〜25 秒に1回` など）やサーバー側のファイル管理事情（`zip そのものはサーバーに残しません` など）の過剰な露出
  2. 標準的な UI 用語を避けたことによる不自然な訓読み・口語表現や造語（「足す」「外す」「変える」「送る」「暦」「入れ子」「予備のコード」「棒を押すと」など）
  3. 画面構成の変更に伴う文言のずれ（「今すぐ調べる」が「このアプリについて」画面へ移動したあとも、場所詳細の未調査メッセージが「取り込み画面の『今すぐ調べる』」のまま残っていた点など）およびバックグラウンド処理（`osm.ts`）の内部ログ文字列（`pid ...` 等）の画面露出
  4. 冗長な文体や細切れの読点
- 上記の総評・用語統一ルール・ファイル別の具体的な修正候補一覧を `memo/doc/gui-format-problem.md` に記録した

## GUI メッセージ・ラベル・エラー文言・CSV 列名の全面見直し
- ユーザーの指示：`memo/doc/gui-format-problem.md` に挙げた修正候補をすべて反映し、あわせて変更された文言が影響するコード内コメントやドキュメント類も現在の文言に合わせる
- 画面（`src/client/`）の修正
  - 用語の統一：「利用者／利用者名」→「ユーザー／ユーザー名」、「暦／暦を隠す」→「カレンダー／カレンダーを閉じる」、「入れ子」→「施設内」、「予備のコード／作り直す」→「バックアップコード／再発行する」、「ファイルを送る／選ぶ」→「ファイルのインポート／ファイルを選択」、「書き出す／読み込む」→「エクスポート／インポート」、「名前を変える／付ける」→「名前・メモを編集／設定」、「足す／外す」→「追加／削除（または解除）」、「タイムラインにある／ない」→「訪問履歴あり／訪問履歴なし」
  - 集計・旅行・場所・保存リストの表記統一：集計単位を「年別／月別／曜日別／時間帯別（開始時刻）／移動手段別」（`aria-label="集計単位"`）に統一し、グラフの説明を「（グラフをクリックすると月別表示に切り替え）」に変更。旅行詳細の見出しも「日別」に統一。場所一覧や保存リストの最終訪問日表記を「最終 YYYY-MM-DD」、読み込み中表示を「読み込んでいます…」、地図ピン上限注記を「（地図表示は上位 N か所）」に統一
  - 説明文・ヘルプ・削除確認文の簡潔化：`ImportView.tsx` や `ServerData.tsx` の説明から内部の距離閾値・秒数・サーバー上の zip 削除挙動などの記述を除き、利用者にとって必要な操作と挙動の説明に整理
  - 「このアプリについて」（`About.tsx`）の項目名を「画面／作成」から「クライアント／ビルド」に変更し、Google Maps API キー未設定時のプレースホルダー表示も明確化
- サーバー（`src/server/`）の修正
  - `labels.ts`：場所詳細画面に出る `pendingNote`・`missingNote` から内部距離閾値や旧画面名（「取り込み画面の〜」）を除き、「次回データ更新時、または『このアプリについて』画面から照合できます」「周辺の該当データなし」に整理
  - `osm.ts`：画面の `ServerData.tsx` に表示される `lastRun.stopped` の文言を、コンソール用の内部ログ（`pid` 等）とは分けて「前回の処理が実行中です」「サーバー混雑または通信制限のため一時中断しました（HTTP 429）」に変更
  - `main.ts`・`userdata.ts`・`takeout.ts`・`swarm.ts`：クライアントへ返す HTTP エラーメッセージ（認証・2 段階認証の確認コード・レート制限・セッション期限切れ・排他ロック競合・インポート検証・パラメータ検証エラーなど）を一般的な UI メッセージに統一
  - `exporter.ts`：CSV エクスポートの列名を画面の表記に合わせて変更（滞在 CSV の「入れ子」→「施設内」、場所 CSV の「初めて／最後／滞在の合計（時間）」→「初回訪問／最終訪問／合計滞在時間（時間）」）
- そのままにしたもの
  - サーバー管理者が CLI で実行するコマンド（`users.ts` 等）のコンソール出力メッセージ
  - 地図の認証失敗時（`maps.ts`）やクライアント未ビルド時（`main.ts`）など、一般利用者が自力で解消できずサーバー管理者の対応が必須となるエラーの「サーバーの管理者に連絡してください。」
- ドキュメント・コメントの更新：`deploy/README.md`、`deploy/make-osm-poi.sh`、`memo/doc/spec.md`、`memo/doc/design.md` および各ソースコード内のコメントを新しい UI 文言に合わせて更新
- 確かめたこと：型チェック（`npm run typecheck`）・ビルド（`npm run build`）
