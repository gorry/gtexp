# 2026-10-08

## 初版（2026.1007.1）を公開
- GitHub（https://github.com/gorry/gtexp）で公開する最初の版。ライセンスは Apache License 2.0（`LICENSE`）、著作権表示と第三者のソフトウェア・データの表示は `NOTICE`
- 機能：タイムラインのエクスポートの取り込み（「共有」からの受け取りを含む）、日付・場所・旅行から見る、検索・集計、書き出し（CSV / KML / GPX / GeoJSON）、場所への名前・メモ・タグ（まとめてタグ付けを含む）、住所・地点名の自動付与（位置参照情報・OpenStreetMap・Google Takeout）、Takeout の保存リストの地図、現在地ボタン、利用者ごとの独立した記録
- 文書：設計方針 `memo/doc/design.md`、仕様 `memo/doc/spec.md`、元データの形式 `memo/doc/timeline-format.md`、設置手順 `deploy/README.md`
- 公開にあたり、作者の環境の情報（サーバーのホスト名・アドレス・ポート、ユーザー名、自宅付近の住所の例、手元のデータの件数など）は、例の値（`gtexp.example.com` など）に置き換えた
- 配布と設置の形：サーバーにリポジトリを `git clone` して `npm ci && npm run build` し、展開したフォルダーをそのまま実行場所にする（`dist/server.mjs`・`dist/public`、設定・`data/`・`log/` も同じフォルダー。更新は `deploy/update.sh`）。手元でビルドして scp で送る `tools/deploy.mjs` は使わない
- 対象の OS：Linux（systemd、Apache / nginx）を主とし、FreeBSD（rc.d、Apache / nginx）でも動く。設定例は `deploy/linux/`・`deploy/freebsd/`、cron・データ取り込み・更新のスクリプトは共通（node は PATH から探し、`NODE=` で指定もできる）
