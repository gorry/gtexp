## 自分のパソコン（Windows・Mac）で使う手順を書く
- ユーザーからの話：（私が試験に使っているように）Windows や Mac にローカルで入れて動かす方法を文書にしてはどうか。ユーザーの判断で、cron が要る機能（毎時の住所の取得）と、位置参照情報・OpenStreetMap のデータは任意として扱い、`check` のサービスの定義などの注意は「無視してよい」と書く
- `deploy/LOCAL.md` を書いた：できること・できないこと（使えるのは起動しているパソコンからだけ、地図は API キーが要る）、Node.js を入れる、取得（Git か ZIP）、`npm ci`・`npm run build`、ユーザーを作る、起動して http://localhost:8787/ を開く、地図（キーの制限に `http://localhost:8787/*`、設定ファイル）、取り込み、更新、データの場所とバックアップ（`session.key` をなくしたとき）、`check` で無視してよい注意、住所・施設名のデータ（cron なしでよい、`.sh` は Windows ではそのまま動かない）、うまく動かないとき（ポートが使われている、Node.js が古い）
- トップの README に「自分のパソコンで使う」の節（LOCAL.md へのリンク）を足し、開発向けの節を「手元で動かす（開発）」にした。deploy/README.md の冒頭からもリンクした
- 確かめたこと（Windows）：GitHub から取得し直して `npm ci`・`npm run build`、設定ファイルなしで `user-add`・`serve`・ログイン・`/api/health`、`check` に出る注意の一覧（文書の「無視してよい」と一致）、Git を使わない取得（`.git` なし）でもビルドでき、ビルドのコミットが空になる、ポートが使われているときのエラーの文。Mac は手元にないので未確認
